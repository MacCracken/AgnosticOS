## What "update" means per repo

For every repo below, when a v5.7.x patch closes:

1. Bump `cyrius = "5.7.X"` pin in `cyrius.cyml`
2. Run `cyrius deps && cyrius build && cyrius test` — must be clean
3. Re-run benchmarks (where applicable — noted inline)
4. Update CHANGELOG with the pin bump
5. Update repo `VERSION` only if a user-facing change warrants it
6. Commit + tag

Per-repo verification: **always check the actual `VERSION` file and `cyrius.cyml` pin before acting on any single item.** Drift caveat applies to this doc too.
