# Server-stage app ports — descent (port now) + agora (kernel gaps)

> **Status**: Planning + in-progress | **Created**: 2026-06-20 | **Owner**: agnosticos (testing surface) → agnos (kernel gaps)
> The two telnet server-stage apps from [`docker-service-sweep-harness.md`](docker-service-sweep-harness.md) §4. **descent** fits agnos's single-thread/epoll model and is being ported now; **agora** is fork-per-accept and needs *kernel* features (don't degrade agora to fit agnos). Derived from a 6-agent map+synthesis workflow (2026-06-20), every load-bearing claim source-verified.

## Key unblock (2026-06-20): the cyrius server-socket peer + the pin bump

The cyrius stdlib **already wires agnos TCP server sockets** — `lib/net.cyr`'s `CYRIUS_TARGET_AGNOS` branch maps `sock_bind`/`sock_listen`/`sock_accept` onto kernel **#56/#57** and `sock_send`/`recv`/`close` onto **#48/#49/#50** (via the `AGNOS_SOCK_TAG=0x40000000` fd→conn_id adapter in `lib/syscalls_x86_64_agnos.cyr`). **This landed at cyrius v6.2.22** — *after* agnos's old 6.2.7 pin, which is exactly why server-app ports were blocked. The 1.45.12 pin bump to **6.2.30** is the unblock: the kernel binary is byte-identical across versions, but **ring-3 consumers (descent/agora) consume the evolving stdlib**, so a current pin is the unblock for *them*. (state.md's "sock_listen/accept still fail-loud on agnos" note was stale — corrected.)

**No agnos *kernel* work is needed for descent** — the ABI (#56/#57/#48–50, epoll #19–21, timerfd #22–23, signalfd #18) is complete.

## descent → agnos port (in progress)

> **UPDATE 2026-06-21 — `--agnos` build is GREEN (compile-complete), 1,473,016 B; Linux stays green at 1,517,184 B.** The lib chain compiles (C1/C2 peer prototype; H1–H5 released as patra 1.12.3 + libro 2.7.6, pending re-vendor), and the **descent-source event-loop port landed** (steps 1, 3, 4, 5 below): `set_nonblock`→no-op, `install_signal_fd`/epoll helpers gated, `EPOLLIN`/`EPOLLOUT` agnos-compat consts, `session_on_readable` agnos branch using **non-blocking `sock_recv`#49** (correct WOULD_BLOCK/EOF inversion), and **`cmd_serve`'s epoll loop → a `sleep_ms`#41-paced poll loop** (drain `sock_accept`#57 → non-blocking recv sweep over `g_session_head` → absolute combat-tick → ~20 ms cadence; in-band/process-kill shutdown). **Remaining (runtime-only, opt-in M6 save path — does NOT block the MUD):** (a) `persist.cyr` `SYS_RENAME_NR`=82 → agnos `rename`#31 (step 6); (b) stdlib `io.cyr` `file_append_locked`/`file_lock_shared`/`file_unlock` are Linux-only → trap-stubs on agnos (filed in the cyrius issue — agnos has flock#59/lseek#58 to implement them). **✅ VALIDATED (2026-06-21, cyrius 6.2.36).** Lib re-vendor done (peer C2 + io.cyr flock helpers folded; patra 1.12.3 / libro 2.7.7 in the chain). Built the server-socket QEMU harness `agnosticos/docker/descent-sweep/` (boot agnos → agnsh `run /bin/descent serve 4000` → host connect over SLIRP hostfwd). **PASS first run:** the full MUD banner + name prompt served, a sent name drew descent's reply ("Welcome, Tester… choose a passphrase") — proving `sock_listen#56`/`accept#57` + the `sleep_ms` poll loop + non-blocking `sock_recv#49` live-session servicing + the libro persist chain (no trap) all run on agnos. descent is the first sovereign ring-3 **network service** validated on agnos. Iron burn optional/future.

descent (`cyrius-yeomans-descent`) is **single-process / single-thread / cooperative** — it has **no fork** (the only `fork` token is a comment in `telnet.cyr:26`). It already keeps an intrusive active-session list (`SS_NEXT`, `session.cyr:38`). So the port is a real but bounded source-level effort, **not** a concurrency-model rewrite.

**The one design-shaping fact:** agnos `epoll` watches **only `VFS_SIGNALFD` + `VFS_TIMERFD`, never sockets** (verified `agnos/kernel/core/syscall.cyr:782–787`), and agnos `sys_epoll_ctl`/`wait` are **3-arg** (no event struct, no per-fd user-data, no timeout). So descent's epoll-as-socket-multiplexer must become an **agnos poll loop**: a `timerfd` (combat-tick cadence) + `signalfd` in the epoll set drive the wakeups, and between wakeups one non-blocking sweep of `sock_accept`#57 + `sock_recv`#49 over descent's own session list. Sockets stay **out** of epoll.

### Risks
- **Large-binary miscompile (HIGH)**: descent is ~1.5 MB. Per [[project_cyrius_pinlag_large_agnos_binary_miscompile]], pick a pin proven large-binary-clean (≥6.1.37 cleared doom@589 KB; verify ≥6.2.22 in QEMU — *compile success ≠ runtime correctness* at this size).
- **recv EOF/WOULD_BLOCK inversion (MEDIUM)**: agnos `sock_recv`#49 returns **0=WOULD_BLOCK, −1=EOF** — inverted from descent's Linux `EAGAIN=−11` logic. The stdlib adapter fixes the *blocking* path; descent's **non-blocking drain** must be audited or it silently drops live sessions / spins on dead ones.
- **8-conn / 8-listener cap (LOW-MED)**: agnos TCP caps at 8 conns; descent's `LISTEN_BACKLOG=32`/`MAX_EPOLL_EVENTS=64` exceed it. Fine for a smoke/small deploy; document the ceiling.
- **Signal delivery unverified (MED)** + **re-vendor SIGILL trap (MED)** — see steps 5/1.

## agora kernel-gap spec — improve the kernel, don't degrade agora

agora is **fork-per-accept** (ADR 0007) with a `flock`'d persistent-universe shared world. It binds on kernel primitives agnos lacks. Below is what agnos must **gain** so agora runs **unmodified** (do NOT rework agora to fit agnos). All three build on the 1.44.x per-process-CR3 + proc-table foundation.

| Feature | Why agora needs it (unmodified) | agnos foundation | Design sketch | Effort | Risk |
|---|---|---|---|---|---|
| **`fork`#58** | `fork-per-accept` (`main.cyr:2261`): a worker per connection with a **private AS copy** (per-conn globals, zero locking), inheriting cfd+sfd. `spawn`#3 (reload ELF) is **not** a substitute; threads aren't drop-in. Without it agora won't even compile for agnos. | `proc_alloc_slot` + `proc_create_full` + `proc_set_cr3`/ring-3; `sched_yield`#44 **is** the "return-twice" mechanism (writes rax via slot `p+112`); `pmm_alloc_2mb` + `proc_map_page` are the dup primitives; `waitpid`#4 is the wait half. | `sys_fork`#58 (IF=0): alloc slot; **`proc_dup_address_space`** (new) walks parent `PD[1..510]` present+user+huge PDEs, `pmm_alloc_2mb`+memcpy+`proc_map_page` per page (**full-copy, not CoW** for v1); seed child slot like `sched_yield` (`p+112`=0 so it returns 0); set CR3+state-ready+ppid; parent returns child pid. FD inheritance via a `proc_fd_owner[32]` tag (vfs_table is one global). | **large** | PMM pressure (full-copy ×8 conns); fd-ownership bug-prone; `ppid` needs a `proc_ppid[16]` array; IF=0-vs-scheduler race. |
| **`flock`#59** ✅ **DONE (2026-06-20)** | agora's **only** cross-process serialization (16 sites; door world `door.cyr:562`, ADR 0010). Without it concurrent door-game turns lose updates. | single-core IF=0 makes a lock table atomic; release hooks ride `close`#6. | **Implemented** (`vfs.cyr`+`syscall.cyr`): `(fd, op)` SH=1/EX=2/UN=8/NB=4; `flock_inode/pid/mode[16]` keyed by inode; EX exclusive, SH coexist, EX-vs-SH conflict → −1 (WOULD_BLOCK, ring-3 poll-spins); **released in `vfs_close`#6 AND on proc exit** (`flock_release_pid`). `FLOCK_SELFTEST` ALL PASS; `check.sh` 11/11. | **medium** ✅ | done; `O_EXCL` a small follow-on. |
| **`lseek`#58** ✅ **DONE (2026-06-20)** | libro/patra's seek-based storage (descent persistence) + general file seek. | `VFS_EXT2_FILE` already carries `pos`@payload[0] / `size`@[1]. | **Implemented**: `(fd, offset, whence)` SET/CUR/END sets `payload[0]`, returns new pos / −1. | small ✅ | done. |
| **`waitpid` wait-any** (extend #4) | the reaper (`main.cyr:2241`) calls `waitpid(-1, WNOHANG)` or zombies fill the proc table. | `waitpid`#4 **already** does WNOHANG for a single pid — only **wait-ANY** is missing. | `arg1 < 0` → scan for `ppid==proc_current && state==0`, reap + return its pid. Needs the same `proc_ppid[16]`. | **small** | small; #4 already covers the WNOHANG semantics. |

**Recommended ordering:** `waitpid` wait-any **first** (it forces the `proc_ppid[16]` array that `fork` also needs) → `fork`#58 (full-copy) → `flock`#59 → `O_EXCL`. QEMU-validate each (the cyrius peer is ready at 6.2.22+).

**Don't-degrade rationale:** agora needs a **real** `fork` (not `spawn`), **full-copy** AS (not CoW shortcuts), **real** `flock` with release-on-last-fd-close, and **wait-any** `waitpid` — this is the *minimum* to run agora unmodified. Degrading agora (e.g. rewriting it to single-process epoll like descent) would throw away its fork-per-accept isolation + persistent-universe model, which is the point of the app.

### Open decision for the user
**Is `fork` wanted now?** It's a **large** kernel effort and agora is the *only* consumer that needs it (descent needs none). Given agora was deferred ("too much to fix right now"), the call is whether to open a `fork`/`flock` kernel arc, or land descent first (zero kernel work) and schedule the agora-enabling kernel features later. This spec is the "where to improve the kernel" answer either way.
