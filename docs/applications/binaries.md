# AGNOS Binaries & Tools — Released (v1.0+)

> Standalone v1.0+ binaries and CLI tools in the AGNOS stack — the kernel, shell, init, package manager, build system, and the sovereign userland (coreutils, editors, viewers, terminal-aesthetics tools). Distinct from the reusable **[library crates](libs/README.md)** and from the larger **[consumer applications](README.md)** (Abacus, Aequi, …).
>
> Pre-1.0 binaries/tools (still scaffolding toward v1.0) live in the [planning registry](../development/planning/shared-crates.md) under *Binaries & Tools (pre-1.0)*. Stdlib-folded distfiles (`sandhi`, `niyama`) are documented under [libs/ § Stdlib-Folded](libs/README.md).
>
> Full cross-repo registry: [Shared Crates Registry](../development/planning/shared-crates.md). Live versions/sizes/cycle state: [development/state.md](../development/state.md). **Verify against each repo's `VERSION` before acting on a single row.**
