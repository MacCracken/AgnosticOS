# agora

Telnet-served BBS — Sigil-backed Ed25519 auth, multi-board threaded boards, three door games + Persistent-Universe shared-world multiplayer (Cyrius-native; binary).

- **Repository**: [github.com/MacCracken/agora](https://github.com/MacCracken/agora)
- **License**: GPL-3.0-only
- **Status**: Stable — v1.0+
- **Language**: Cyrius

Greek ἀγορά — *civic marketplace / public assembly*. Fork-per-connection concurrency, full telnet RFC conformance; door games PA / Smuggler / The Handler with `flock`'d shared-world state. Anchors the BBS/MUD aesthetic cluster.
