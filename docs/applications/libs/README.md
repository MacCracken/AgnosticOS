# AGNOS Shared Library Crates

> Reusable library crates that form the AGNOS stack. Consumer [applications](../README.md) depend on these — they should never depend on external libraries when an AGNOS crate covers the domain.
>
> **78 crates** — see [Shared Crates Registry](../../development/applications/shared-crates.md) for the authoritative version list.
>
> **Last Updated**: 2026-04-14

This directory contains per-crate profile docs for non-ported (Rust-era) libraries. Cyrius-ported crate profiles have been archived to `docs/archive/libs-pre-cyrius/` — their repos' own CLAUDE.md files are now authoritative.
